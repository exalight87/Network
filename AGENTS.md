# Repository working agreement

- Split substantial requests into small, independently useful implementation steps.
- Run the checks relevant to each step before committing it.
- Commit every completed step with an explicit Conventional Commits message.
- Stage only files that belong to the current step; never use broad staging commands when unrelated changes exist.
- Never modify, discard, stage, or commit pre-existing or unrelated local changes.
- Report the checks run and the commits created when handing work back to the user.
